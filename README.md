## Included
- `T47_SEO_Product_Description_Generator_COMPLETE.xlsx` — project workbook
- `app.py` — Streamlit interactive UI
- `requirements.txt` — Python dependencies
- `MASTER_PROMPT.txt` — reusable app-generation / project prompt

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`.
4. Run `streamlit run app.py`.
5. Keep the Excel workbook in the same folder as `app.py`.

## Generation modes
- **Demo mode:** works without an API key and is useful for UI demonstration.
- **Gemini API:** enter your own Gemini API key at runtime. Never hard-code the key or place it in the workbook.
